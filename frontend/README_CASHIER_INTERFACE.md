# 🍔 Интерфейс кассира - Новая версия для планшета

## 📱 Описание

Новый интерфейс кассира создан специально для планшетов и состоит из **3 колонок** для удобного управления заказами:

### 🔄 Три статуса заказов:

1. **🔵 Готовятся** - заказы в процессе приготовления
2. **🟢 Готовы** - заказы готовы к выдаче/доставке  
3. **⚫ Завершенные** - завершенные заказы

## 🎯 Функциональность

### Статистика в верхней части:
- **Всего заказов** - общее количество заказов
- **Готовятся** - количество заказов в процессе
- **Готовы** - количество готовых заказов
- **Завершены** - количество завершенных заказов

### Управление заказами:
- **Начать приготовление** - переводит заказ в статус "Готовится"
- **Готов** - переводит заказ в статус "Готовы"
- **Завершить** - завершает заказ

## 📋 Информация о заказе

Каждый заказ отображает:
- **Номер заказа** и время создания
- **Информация о клиенте** (имя, телефон)
- **Адрес доставки** (если доставка)
- **Список блюд** с размерами и добавками
- **Итоговая стоимость**
- **Заметки клиента** (если есть)
- **Тип заказа** (самовывоз/доставка)

## 🎨 Дизайн для планшета

### Особенности:
- **3 равные колонки** для удобного просмотра
- **Цветовая индикация** статусов заказов
- **Крупные кнопки** для удобного нажатия
- **Адаптивная высота** колонок
- **Прокрутка** в каждой колонке при большом количестве заказов

### Цветовая схема:
- **Синий** (#3b82f6) - Готовятся
- **Зеленый** (#10b981) - Готовы  
- **Серый** (#6b7280) - Завершенные

## 🚀 Как использовать

### 1. Вход в систему
```
URL: http://localhost:5173/cashier/login
```

### 2. Рабочий интерфейс
```
URL: http://localhost:5173/cashier/dashboard
```

### 3. Рабочий процесс:
1. **Новый заказ** появляется в колонке "Готовятся"
2. **Нажмите "Начать приготовление"** - заказ переходит в статус "Готовится"
3. **Нажмите "Готов"** - заказ переходит в колонку "Готовы"
4. **Нажмите "Завершить"** - заказ переходит в колонку "Завершенные"

## 📱 Адаптивность

Интерфейс оптимизирован для:
- **Планшеты** (основной формат)
- **Большие экраны** (десктоп)
- **Мобильные устройства** (с горизонтальной прокруткой)

## 🔧 Технические детали

### Компоненты:
- `CashierStats` - статистика в верхней части
- `OrderColumn` - колонка с заказами
- `CashierDashboardPage` - главная страница

### API методы:
- `getDashboardStats()` - получение статистики
- `getOrders()` - получение списка заказов
- `startProcessingOrder()` - начать приготовление
- `markOrderReady()` - отметить как готовый
- `completeOrder()` - завершить заказ

## 🎯 Преимущества нового интерфейса

1. **Удобство** - все заказы видны одновременно
2. **Скорость** - быстрые действия одним кликом
3. **Наглядность** - цветовая индикация статусов
4. **Эффективность** - оптимизированный рабочий процесс
5. **Мобильность** - адаптивность для разных устройств

## 📊 Статистика в реальном времени

Интерфейс автоматически обновляет:
- Количество заказов в каждой колонке
- Общую статистику в верхней части
- Статусы заказов при выполнении действий
