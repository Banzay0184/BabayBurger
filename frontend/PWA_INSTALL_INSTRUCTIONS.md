# 📱 Инструкция по установке PWA кассира

## 🚀 Быстрый старт

1. **Откройте кассира**: `http://localhost:5173/cashier.html`
2. **Дождитесь загрузки** (2-3 секунды)
3. **Найдите кнопку "📱 Установить PWA"** в левом верхнем углу
4. **Следуйте инструкциям** в диалоговом окне

## 🔍 Способы установки

### Способ 1: Автоматический prompt (Chrome/Edge)
- Дождитесь появления иконки ⊕ в адресной строке
- Нажмите на неё и подтвердите установку

### Способ 2: Через меню браузера
**Chrome/Edge:**
1. Меню (⋮) → "Установить Babay Кассир"
2. Подтвердите установку

**Safari (iOS):**
1. Поделиться → "На экран Домой"
2. Нажмите "Добавить"

### Способ 3: Через DevTools (для разработчиков)
1. F12 → Application → Manifest
2. Нажмите "Add to homescreen"

### Способ 4: Принудительная кнопка
- На странице появится кнопка "📱 Установить PWA"
- Нажмите на неё для получения инструкций

## ✅ Проверка успешной установки

**PWA установлено правильно, если:**
- ✅ Приложение открывается без адресной строки
- ✅ В консоли: `Display Mode: standalone`
- ✅ Есть ярлык на рабочем столе/в меню приложений
- ✅ В заголовке окна: "Babay Кассир"

## 🐛 Решение проблем

### Проблема: "Иконка установки не появляется"

**Решения:**
1. **Обновите страницу** (Ctrl+R)
2. **Откройте в режиме инкогнито**
3. **Очистите кэш браузера**
4. **Проверьте в DevTools**:
   - Application → Manifest (должен загружаться без ошибок)
   - Application → Service Workers (должен быть активен)

### Проблема: "beforeinstallprompt не срабатывает"

**Возможные причины:**
- PWA уже установлено
- Запущено в Telegram WebApp (не поддерживает PWA)
- Браузер не поддерживает PWA
- Критерии установки не выполнены

**Решения:**
1. Откройте **в обычном браузере** (не в Telegram)
2. Используйте **Chrome или Edge**
3. Убедитесь, что **Service Worker активен**
4. Проверьте **консоль на ошибки**

### Проблема: "Открывается в браузере после установки"

**Проверьте:**
1. **Запускаете ли из правильного ярлыка** (не из браузера)
2. **Манифест загружается** без ошибок
3. **Service Worker активен**
4. **Display mode** в консоли должен быть `standalone`

## 🧪 Диагностика

### В консоли браузера:
```javascript
// Запустите для полной диагностики
testPWA()

// Проверьте режим отображения
console.log('Display mode:', window.matchMedia('(display-mode: standalone)').matches ? 'standalone' : 'browser');

// Проверьте Service Worker
navigator.serviceWorker.getRegistrations().then(console.log);
```

## 📋 Чек-лист для установки

- [ ] Открыто в Chrome/Edge браузере
- [ ] НЕ в Telegram WebApp
- [ ] Service Worker активен (консоль)
- [ ] Манифест загружается без ошибок
- [ ] Нет ошибок в консоли
- [ ] Попробовали обновить страницу
- [ ] Попробовали режим инкогнито

## 🎯 Если ничего не помогает

1. **Очистите все данные браузера** для сайта
2. **Перезапустите браузер**
3. **Попробуйте другой браузер** (Chrome/Edge)
4. **Откройте DevTools** и проверьте ошибки
5. **Используйте принудительную установку** через DevTools

## 📞 Техническая поддержка

При проблемах приложите скриншоты:
1. **Консоли браузера** с логами
2. **DevTools → Application → Manifest**
3. **DevTools → Application → Service Workers**

PWA должен работать! 🎉
