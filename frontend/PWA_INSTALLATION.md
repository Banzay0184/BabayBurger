# 📱 Правильная установка PWA

## 🎯 Проблема

Ранее при установке PWA с любой страницы устанавливалась клиентская версия, потому что клиентский манифест имел `scope: "/"`, что означало, что он применялся ко всему сайту.

## ✅ Решение

Созданы отдельные страницы для установки PWA с правильными манифестами:

### 📁 Структура файлов

```
HTML файлы:
├── index.html             # Основной интерфейс (без PWA)
├── client.html            # Клиентский интерфейс (без PWA)
├── cashier.html           # Интерфейс кассира с PWA
├── operator.html          # Интерфейс оператора с PWA
├── pwa.html              # Страница выбора PWA
└── pwa-selector.html     # Детальная страница выбора PWA

Манифесты:
├── manifest.json          # Манифест кассира (scope: /cashier)
└── operator-manifest.json # Манифест оператора (scope: /operator)

Service Workers:
├── sw.js                  # Service Worker кассира
└── operator-sw.js         # Service Worker оператора
```

## 🚀 Как установить PWA

### 1. Для оператора
1. **Откройте** `/operator.html` в браузере
2. **Дождитесь** появления prompt установки
3. **Нажмите** "Установить" или используйте кнопку в интерфейсе
4. **Проверьте**, что установлено приложение оператора

### 2. Для кассира
1. **Откройте** `/cashier.html` в браузере
2. **Дождитесь** появления prompt установки
3. **Нажмите** "Установить" или используйте кнопку в интерфейсе
4. **Проверьте**, что установлено приложение кассира

### 3. Через страницу выбора
1. **Откройте** `/pwa.html` или `/pwa-selector.html`
2. **Выберите** нужный интерфейс
3. **Перейдите** на соответствующую страницу
4. **Установите** PWA

## 📱 Манифесты

### Манифест кассира (`manifest.json`)
```json
{
  "name": "Babay Burger - Кассир",
  "short_name": "Babay Кассир",
  "start_url": "/cashier",
  "scope": "/cashier",
  "theme_color": "#f97316",
  "orientation": "portrait-primary"
}
```

### Манифест оператора (`operator-manifest.json`)
```json
{
  "name": "Babay Burger - Оператор",
  "short_name": "Babay Оператор",
  "start_url": "/operator",
  "scope": "/operator",
  "theme_color": "#3b82f6",
  "orientation": "landscape-primary"
}
```

## 🔧 Service Workers

### Service Worker кассира (`sw.js`)
- Кэширует ресурсы для `/cashier`
- Обрабатывает API запросы кассира
- Push уведомления для кассира

### Service Worker оператора (`operator-sw.js`)
- Кэширует ресурсы для `/operator`
- Обрабатывает API запросы оператора
- Push уведомления для оператора

## 🎯 Результат

Теперь каждый интерфейс имеет свой собственный PWA:

- **Кассир** (`/cashier.html`) → устанавливается приложение кассира  
- **Оператор** (`/operator.html`) → устанавливается приложение оператора
- **Клиент** (`/client.html`) → без PWA (чтобы не конфликтовать)
- **Основной** (`/index.html`) → без PWA (чтобы не конфликтовать)

## 🔍 Тестирование

1. **Откройте** `/operator.html` в браузере
2. **Дождитесь** появления prompt установки
3. **Установите** приложение
4. **Проверьте**, что установлено приложение оператора с правильным названием и иконкой

5. **Откройте** `/cashier.html` в браузере
6. **Дождитесь** появления prompt установки
7. **Установите** приложение
8. **Проверьте**, что установлено приложение кассира с правильным названием и иконкой

## 📝 Примечания

- Каждый манифест имеет свой `scope`, что предотвращает конфликты
- Service Workers регистрируются только для соответствующих интерфейсов
- PWA компоненты автоматически определяют правильный контекст
- Клиентский интерфейс не имеет PWA, чтобы не конфликтовать с административными разделами

## 🚨 Важно

- **НЕ устанавливайте** PWA с главной страницы (`/index.html`) или клиентской страницы (`/client.html`)
- **Устанавливайте** PWA только с `/operator.html` или `/cashier.html`
- **Используйте** `/pwa.html` или `/pwa-selector.html` для выбора интерфейса
