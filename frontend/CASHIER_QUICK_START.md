# 🏪 Быстрый старт - Интерфейс кассира

## 🚀 Запуск

```bash
# В папке frontend
npm run dev:cashier
```

Откроется: `http://localhost:5173/cashier.html`

## 🔑 Тестовые данные

- **Логин:** `cashier_babay1`
- **Пароль:** `cashier123`

## 📋 Workflow заказа

1. **Оператор** обрабатывает заказ → статус `confirmed`
2. **Кассир** видит заказ → нажимает **"Начать приготовление"** → статус `preparing`
3. **Кассир** готовит → нажимает **"Готов"** → статус `ready_for_delivery`
4. **Кассир** завершает → нажимает **"Завершить"** → статус `completed`

## 🎯 Функции

- ✅ Просмотр заказов ресторана
- ✅ Управление статусами заказов
- ✅ Статистика в реальном времени
- ✅ Безопасность (только заказы своего ресторана)
