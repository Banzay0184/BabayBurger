# 🧪 Руководство по тестированию PWA кассира

## 🔍 Диагностика проблем с PWA

### 1. Проверьте консоль браузера

Откройте DevTools (F12) и проверьте консоль на наличие сообщений:

```
💰 PWA Diagnostics:
- User Agent: [информация о браузере]
- HTTPS: true/false
- Service Worker Support: true/false
- Manifest Support: true/false
- Current URL: [текущий URL]
- Display Mode: standalone/browser
```

### 2. Проверьте манифест

В DevTools перейдите в **Application > Manifest**:
- Убедитесь, что манифест загружается без ошибок
- Проверьте, что все иконки доступны
- Убедитесь, что `display` установлен в `standalone`

### 3. Проверьте Service Worker

В DevTools перейдите в **Application > Service Workers**:
- Убедитесь, что Service Worker зарегистрирован
- Проверьте статус: должен быть "activated and running"
- Если есть ошибки, перезагрузите страницу

## 🚀 Пошаговое тестирование

### Шаг 1: Запуск в режиме разработки

```bash
cd frontend
npm run dev
```

Откройте: `http://localhost:5173/cashier.html`

### Шаг 2: Проверка критериев PWA

PWA будет работать только если выполнены все условия:

1. **HTTPS или localhost** ✅ (localhost работает)
2. **Манифест подключен** ✅ 
3. **Service Worker зарегистрирован** ✅
4. **Минимум 2 иконки** (192x192 и 512x512) ✅

### Шаг 3: Тестирование установки

1. **Chrome/Edge**:
   - Дождитесь появления иконки установки в адресной строке
   - Или используйте меню: ⋮ > "Установить Babay Кассир"
   - Или дождитесь кастомного prompt (через 3 сек)

2. **Chrome DevTools**:
   - Application > Manifest > "Add to homescreen"

### Шаг 4: Проверка standalone режима

После установки:
1. Закройте браузер
2. Найдите "Babay Кассир" в приложениях
3. Запустите - должно открыться без адресной строки
4. В консоли должно быть: `Display Mode: standalone`

## 🐛 Решение проблем

### Проблема: "beforeinstallprompt не срабатывает"

**Возможные причины:**
1. Уже установлено как PWA
2. Критерии PWA не выполнены
3. Браузер не поддерживает PWA
4. Недавно отклонили установку

**Решение:**
```javascript
// Проверьте в консоли:
console.log('Display mode:', window.matchMedia('(display-mode: standalone)').matches);

// Принудительно очистите данные:
// DevTools > Application > Storage > Clear storage
```

### Проблема: "Service Worker не регистрируется"

**Возможные причины:**
1. Файл `/cashier-sw.js` не найден
2. Ошибки в коде Service Worker
3. Проблемы с CORS

**Решение:**
1. Проверьте, что файл доступен: `http://localhost:5173/cashier-sw.js`
2. Проверьте консоль на ошибки
3. Перезагрузите с очисткой кэша (Ctrl+Shift+R)

### Проблема: "Манифест не загружается"

**Возможные причины:**
1. Неверный путь к манифесту
2. Ошибки в JSON
3. Проблемы с иконками

**Решение:**
1. Проверьте доступность: `http://localhost:5173/cashier-manifest.json`
2. Проверьте JSON валидность
3. Убедитесь, что все иконки существуют

## 🔧 Принудительное тестирование

### Метод 1: Chrome DevTools

1. F12 > Application > Manifest
2. Нажмите "Add to homescreen"
3. Подтвердите установку

### Метод 2: Chrome Flags

1. Откройте: `chrome://flags/`
2. Найдите: "Desktop PWAs"
3. Установите: "Enabled"
4. Перезапустите Chrome

### Метод 3: Симуляция мобильного

1. F12 > Toggle device toolbar
2. Выберите мобильное устройство
3. Перезагрузите страницу
4. Проверьте появление prompt

## 📱 Тестирование на мобильных

### Android Chrome

1. Откройте `https://yourdomain.com/cashier.html`
2. Меню > "Добавить на главный экран"
3. Или дождитесь автоматического prompt

### iOS Safari

## 🎯 Критерии успешной установки

✅ **PWA установлено правильно, если:**

1. Приложение открывается без адресной строки
2. В консоли: `Display Mode: standalone`
3. Есть иконка на рабочем столе/в меню приложений
4. Service Worker активен
5. Работает в офлайн режиме (базовые функции)

❌ **PWA не работает, если:**

1. Открывается в браузере с адресной строкой
2. В консоли: `Display Mode: browser`
3. Нет prompt для установки
4. Ошибки Service Worker в консоли

## 🚨 Частые ошибки

### 1. Неправильные пути в манифесте
```json
// ❌ Неправильно
"start_url": "./cashier.html"

// ✅ Правильно  
"start_url": "/cashier.html"
```

### 2. Отсутствие иконок
```json
// ❌ Файлы не существуют
"src": "/cashier-icon-192.png"

// ✅ Используем существующие
"src": "/logo.jpg"
```

### 3. Service Worker в неправильной папке
```
❌ src/cashier-sw.js
✅ public/cashier-sw.js
```

## 🔄 Сброс PWA для повторного тестирования

1. **Chrome DevTools**:
   - Application > Storage > Clear storage
   - Application > Service Workers > Unregister

2. **Удаление установленного PWA**:
   - Chrome: chrome://apps/ > Удалить
   - Windows: Параметры > Приложения > Babay Кассир > Удалить

3. **Очистка кэша браузера**:
   - Ctrl+Shift+Delete > Очистить всё

После этого можно тестировать установку заново.

## 📞 Поддержка

Если PWA всё ещё не работает:

1. Проверьте все сообщения в консоли
2. Убедитесь, что используете поддерживаемый браузер
3. Проверьте, что все файлы доступны
4. Попробуйте в режиме инкогнито
