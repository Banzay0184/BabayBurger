# Исправление проблем с загрузкой модулей и TronWeb

## Проблемы, которые были исправлены:

### 1. Ошибка MIME type для модулей
**Проблема:** `Failed to load module script: Expected a JavaScript-or-Wasm module script but the server responded with a MIME type of "text/html"`

**Решение:**
- Обновлен `vercel.json` с правильными заголовками для JS и CSS файлов
- Добавлены правила для `/assets/*` и `/*.js` файлов
- Обновлен `_redirects` для Netlify

### 2. Конфликт инициализации TronWeb
**Проблема:** `TronWeb is already initiated. TronLink will overwrite the current instance`

**Решение:**
- Добавлена проверка существования `window.TronWeb` в HTML
- Добавлено логирование для диагностики внешних библиотек
- Предотвращение перезаписи существующих экземпляров

### 3. Конфигурация сборки Vite
**Проблема:** Неправильная обработка модулей в продакшене

**Решение:**
- Обновлен `vite.config.ts` с правильными настройками output
- Изменена минификация с `terser` на `esbuild`
- Добавлены настройки для правильной обработки модулей

## Файлы, которые были изменены:

1. `vercel.json` - добавлены правильные заголовки для статических файлов
2. `public/_redirects` - обновлены правила перенаправления
3. `vite.config.ts` - исправлена конфигурация сборки
4. `cashier.html` - добавлена обработка конфликтов с внешними библиотеками
5. `public/cashier/index.html` - обновлен с диагностикой TronWeb

## Инструкции для деплоя:

1. **Сборка проекта:**
   ```bash
   npm run build
   ```

2. **Проверка собранных файлов:**
   - Убедитесь, что в `dist/` есть файлы `cashier.html` и `assets/main-*.js`
   - Проверьте, что скрипт в HTML ссылается на правильный JS файл

3. **Деплой:**
   - Загрузите содержимое папки `dist/` на ваш хостинг
