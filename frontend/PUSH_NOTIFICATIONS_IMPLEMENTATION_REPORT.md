## 🔧 Service Worker интеграция

### Обработка Push событий
```javascript
self.addEventListener('push', (event) => {
  let notificationData = {
    title: 'Babay Burger - Оператор',
    body: 'Новое уведомление',
    icon: '/logobabay.png',
    badge: '/logobabay.png',
    tag: 'operator-notification',
    requireInteraction: true,
    actions: [...],
    data: { timestamp: Date.now(), type: 'default' }
  };

  // Если есть данные в push событии, используем их
  if (event.data) {
    const pushData = event.data.json();
    notificationData = { ...notificationData, ...pushData };
  }

  event.waitUntil(
    self.registration.showNotification(notificationData.title, notificationData)
  );
});
```

### Обработка кликов
```javascript
self.addEventListener('notificationclick', (event) => {
  event.notification.close();
  
  const notificationData = event.notification.data || {};
  const action = event.action || 'default';
  
  let targetUrl = '/operator/#/dashboard';
  
  // Определяем URL в зависимости от типа уведомления
  if (notificationData.orderId) {
    targetUrl = `/operator/#/dashboard?order=${notificationData.orderId}`;
  }
  
  // Открываем/фокусируем окно
  event.waitUntil(
    clients.matchAll({ type: 'window', includeUncontrolled: true })
      .then((clientList) => {
        for (const client of clientList) {
          if (client.url.includes('/operator/') && 'focus' in client) {
            return client.focus().then(() => {
              return client.navigate(targetUrl);
            });
          }
        }
        return clients.openWindow(targetUrl);
      })
  );
});
```

- **Звуковые уведомления** работают когда вкладка активна
- **Автоматическое определение** активности вкладки
- **Синхронизация настроек** между звуками и Push

### WebSocket интеграция
```typescript
// В useOperatorWebSocket.ts
case 'order_created':
  if ((message as any).order) {
    const order = (message as any).order;
    
    // Отправляем Push-уведомление
    sendOrderNotification(order.id, 'new', {
      orderData: order,
      timestamp: Date.now()
    });
    
    // Воспроизводим звук (если вкладка активна)
    if (config?.enabled) {
      playSound('new_order');
    }
  }
  break;
```

## 📱 Работа в фоне

### Когда вкладка неактивна
- ✅ **Push-уведомления работают** через Service Worker
- ✅ **Звуки отключены** (экономия ресурсов)
- ✅ **Уведомления показываются** в системном трее
- ✅ **Клики открывают приложение** и фокусируют нужную страницу

### Когда вкладка активна
- ✅ **Push-уведомления работают** (дублирование для надежности)
- ✅ **Звуки работают** через Web Audio API
- ✅ **Визуальные уведомления** в интерфейсе
- ✅ **Мгновенная реакция** на события
