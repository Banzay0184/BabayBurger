# 🔧 Решение проблемы "Manifest link not found in HTML"

## ❌ Проблема
Ошибка: **"Manifest link not found in HTML"**
- Манифест не найден в HTML документе
- PWA файлы недоступны
- Кнопка установки не появляется

## 🔍 Причины проблемы

### 1. **Неправильные пути к файлам**
- Сервер разработки не обслуживает файлы из корня public
- Относительные пути работают лучше чем абсолютные

### 2. **Проблемы с сервером разработки**
- Vite может не обслуживать статические файлы правильно
- CORS проблемы с локальными файлами

### 3. **Отсутствие fallback механизма**
- Нет резервного способа загрузки манифеста

## ✅ Решение

### 1. **Исправлены пути к файлам**
```html
<!-- Было -->
<link rel="manifest" href="/operator-manifest.json" />
navigator.serviceWorker.register('/operator-sw.js')

<!-- Стало -->
<link rel="manifest" href="./operator-manifest.json" />
navigator.serviceWorker.register('./operator-sw.js')
```

### 2. **Добавлен встроенный манифест как fallback**
```html
<!-- Встроенный манифест как fallback -->
<script type="application/json" id="pwa-manifest">
{
  "name": "Babay Burger - Оператор",
  "short_name": "Babay Оператор",
  "description": "Интерфейс оператора для управления заказами",
  "start_url": "/operator/",
  "display": "standalone",
  "icons": [...]
}
</script>
```

### 3. **Добавлен PWA File Checker**
- **Компонент `PWAFileChecker`** для проверки доступности файлов
- Тестирует разные пути к файлам
- Показывает прямые ссылки для тестирования

### 4. **Улучшен Manifest Tester**
- Проверяет как внешний, так и встроенный манифест
- Детальная диагностика ошибок
- Рекомендации по исправлению
