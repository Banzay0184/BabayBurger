## 🔧 Настройки звука

### Доступные настройки
```typescript
interface SoundNotificationConfig {
  enabled: boolean;           // Включить/выключить все звуки
  volume: number;            // Громкость (0-1)
  newOrderSound: boolean;    // Звук для новых заказов
  orderUpdateSound: boolean; // Звук для обновлений
  notificationSound: boolean; // Звук для уведомлений
  customSoundUrl?: string;   // Пользовательский звук (будущая функция)
}
```

### Автоматическое сохранение
- Настройки сохраняются в `localStorage` с ключом `operator_sound_config`
- Статистика сохраняется в `localStorage` с ключом `sound_stats`
- Автоматическое восстановление при загрузке страницы

## 📝 Инструкции по использованию

### Для операторов
1. Откройте дашборд оператора
2. Нажмите кнопку 🔊 в правом верхнем углу
3. Настройте звуки по своему усмотрению
4. Используйте кнопку "Тест звука" для проверки
5. Настройки сохраняются автоматически

### Для разработчиков
1. Импортируйте `useSoundNotifications` хук
2. Используйте `playSound(type)` для воспроизведения
3. Подписывайтесь на события `soundPlayed` для мониторинга
4. Настройки доступны через `config` объект
