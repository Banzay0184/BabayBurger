# 🚀 Операторский интерфейс Babay Burger

## 📋 Обзор

Операторский интерфейс - это веб-приложение для операторов ресторана, позволяющее управлять заказами, общаться с клиентами и отслеживать статусы доставки.

## ✨ Основные возможности

### 🔐 Аутентификация
- **Вход оператора** - логин/пароль
- **Регистрация** - создание нового аккаунта оператора
- **Автоматический вход** - сохранение токена в localStorage

### 📊 Дашборд
- **Статистика заказов** - общее количество, новые, в обработке, завершенные
- **Прогресс выполнения** - визуальные индикаторы по статусам
- **Зоны доставки** - список назначенных оператору зон
- **Автообновление** - каждые 30 секунд

### 📋 Управление заказами
- **Просмотр заказов** - полная информация о заказе, клиенте, адресе
- **Фильтрация** - по статусу, зоне доставки, дате
- **Действия оператора**:
  - Назначить заказ себе
  - Начать обработку
  - Звонить клиенту
  - Обновлять результат звонка
  - Добавлять заметки

### 🔔 Уведомления
- **Real-time уведомления** о новых заказах
- **Группировка** по типам
- **Отметка прочитанными**
- **История уведомлений**


## 🚀 Запуск

### 1. Установка зависимостей
```bash
cd frontend
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env.local`:
```env
VITE_API_BASE_URL=https://your-backend-url.com
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```

### 4. Открытие в браузере
Перейдите по адресу: `http://localhost:5173/operator`

## 📱 Использование

### Вход в систему
1. Откройте `/operator/login`
2. Введите логин и пароль
3. Или создайте новый аккаунт через регистрацию

### Работа с заказами
1. **Новые заказы** - автоматически появляются в списке
2. **Назначение** - нажмите "Назначить себе" для взятия заказа в работу
3. **Обработка** - начните обработку после назначения
4. **Звонок клиенту** - отметьте, что позвонили клиенту
5. **Результат звонка** - выберите результат (подтвердил, отменил, изменил и т.д.)

### Фильтрация и поиск
- **По статусу** - выберите нужный статус заказа
- **По зоне** - фильтруйте по зонам доставки
- **Быстрые фильтры** - кнопки для популярных статусов

### Уведомления
- **Просмотр** - нажмите на колокольчик в верхней панели
- **Отметка прочитанными** - нажмите "Отметить прочитанным"
- **Автообновление** - новые уведомления появляются автоматически

## 🔧 API Endpoints

### Аутентификация
- `POST /api/operator/auth/login/` - вход оператора
- `POST /api/operator/auth/logout/` - выход оператора
- `POST /api/operator/auth/register/` - регистрация оператора

### Заказы
- `GET /api/operator/operator-orders/dashboard/` - дашборд
- `GET /api/operator/operator-orders/` - список заказов
- `GET /api/operator/operator-orders/{id}/` - детали заказа
- `POST /api/operator/operator-orders/{id}/assign_to_me/` - назначить себе
- `POST /api/operator/operator-orders/{id}/start_processing/` - начать обработку
- `POST /api/operator/operator-orders/{id}/call_customer/` - отметить звонок
- `POST /api/operator/operator-orders/{id}/update_call_result/` - результат звонка
- `POST /api/operator/operator-orders/{id}/add_notes/` - добавить заметки

### Уведомления
- `GET /api/operator/notifications/` - список уведомлений
- `POST /api/operator/notifications/mark_read/` - отметить прочитанным
- `GET /api/operator/notifications/unread_count/` - количество непрочитанных

## 🎨 Кастомизация

### Цветовая схема
Основные цвета определены в Tailwind CSS:
- **Синий** (`blue-600`) - основные действия, ссылки
- **Зеленый** (`green-600`) - успешные действия, подтверждения
- **Красный** (`red-600`) - ошибки, отмены
- **Желтый** (`yellow-500`) - новые заказы, предупреждения
- **Фиолетовый** (`purple-500`) - обработка, промежуточные статусы

### Темы
Интерфейс использует темную тему (`bg-gray-900`, `bg-gray-800`) для лучшего восприятия в операторских условиях.
