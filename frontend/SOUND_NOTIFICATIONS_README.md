# 🔊 Система звуковых уведомлений для оператора

## Обзор

Система звуковых уведомлений предоставляет операторам возможность получать аудио-уведомления о различных событиях в реальном времени через WebSocket соединение.

## 🎯 Основные функции

### ✅ Реализованные функции

- **Звуковые уведомления для новых заказов** - высокий тон (800Hz)
- **Звуковые уведомления для обновлений заказов** - средний тон (600Hz)  
- **Звуковые уведомления для системных уведомлений** - низкий тон (400Hz)
- **Настройка громкости** - от 0% до 100%
- **Индивидуальное включение/выключение** для каждого типа звука
- **Автоматическое сохранение настроек** в localStorage
- **Тестирование звука** - кнопка для проверки
- **Статистика воспроизведения** - счетчики для каждого типа звука
- **Визуальные индикаторы** - анимации при воспроизведении

## 🏗️ Архитектура

### Компоненты

1. **`SoundNotificationManager.tsx`** - основной компонент управления звуками

### Интеграция

- **Модальное окно настроек** - полный контроль над звуками

## 🎵 Типы звуков

### Новые заказы (800Hz)
- **Частота:** 800Hz
- **Длительность:** 300ms
- **Затухание:** Экспоненциальное
- **Громкость:** 30% от максимальной

### Обновления заказов (600Hz)
- **Частота:** 600Hz
- **Длительность:** 300ms
- **Затухание:** Экспоненциальное
- **Громкость:** 20% от максимальной

### Системные уведомления (400Hz)
- **Частота:** 400Hz
- **Длительность:** 300ms
- **Затухание:** Экспоненциальное
- **Громкость:** 25% от максимальной

## ⚙️ Настройки

### Основные настройки
```typescript
interface SoundNotificationConfig {
  enabled: boolean;           // Включить/выключить звуки
  volume: number;            // Громкость (0-1)
  newOrderSound: boolean;    // Звук для новых заказов
  orderUpdateSound: boolean; // Звук для обновлений
  notificationSound: boolean; // Звук для уведомлений
  customSoundUrl?: string;   // Пользовательский звук
}
```

### Сохранение настроек
- Настройки автоматически сохраняются в `localStorage`
- Ключ: `operator_sound_config`
- Формат: JSON

## 🔧 Использование

### Базовое использование
```typescript
import { useSoundNotifications } from './SoundNotificationManager';

const MyComponent = () => {
  const { playSound, config, updateConfig } = useSoundNotifications();
  
  // Воспроизвести звук
  playSound('new_order');
  
  // Обновить настройки
  updateConfig({ volume: 0.8 });
};
```

### Интеграция с WebSocket
```typescript
// В useOperatorWebSocket.ts
const handleMessage = useCallback((message: WebSocketMessage) => {
  switch (message.type) {
    case 'order_created':
      playSound('new_order'); // Автоматическое воспроизведение
      break;
    case 'order_updated':
      playSound('order_update');
      break;
    case 'notification':
      playSound('notification');
      break;
  }
}, [playSound]);
```

## 🤝 Поддержка

При возникновении проблем с звуковыми уведомлениями:

1. Проверьте настройки браузера для автовоспроизведения
2. Убедитесь, что звук включен в системе
3. Проверьте консоль браузера на наличие ошибок
4. Попробуйте кнопку "Тест звука" в настройках

**Примечание:** Некоторые браузеры требуют пользовательского взаимодействия перед воспроизведением звука в первый раз.
