## 🧪 Что нужно протестировать СЕЙЧАС:

### **Для кассира в Telegram:**

1. **Обновите страницу кассира в Telegram**
2. **Откройте консоль браузера (F12)**
3. **Должны увидеть:**
   ```
   🔍 TELEGRAM DETECTION:
   - window.Telegram exists: true
   - window.Telegram.WebApp exists: true
   - isTelegramWebApp: true
   - isInWebView: true
   🚨 PWA НЕ РАБОТАЕТ В TELEGRAM WEBAPP ИЛИ WEBVIEW!
   📱 ДЛЯ УСТАНОВКИ PWA ОТКРОЙТЕ ССЫЛКУ В ОБЫЧНОМ БРАУЗЕРЕ
   ⚠️ Показываем предупреждение о Telegram WebApp...
   ```

4. **Должно появиться модальное окно** с предупреждением
5. **Нажмите "📋 Копировать ссылку"**
6. **Откройте Chrome/Safari**
7. **Вставьте ссылку и перейдите**

### **Для кассира в Chrome/Safari:**

1. **После перехода по ссылке должны увидеть:**
   ```
   🔍 TELEGRAM DETECTION:
   - window.Telegram exists: false
   - window.Telegram.WebApp exists: false
   - isTelegramWebApp: false
   - isInWebView: false
   ✅ НЕ TELEGRAM WEBAPP - PWA МОЖЕТ РАБОТАТЬ
   ```

2. **Через 2-3 секунды должна появиться кнопка/иконка установки PWA**
3. **Установите PWA**
4. **Проверьте, что открывается в standalone режиме**

### **Для оператора:**

1. **Обновите страницу оператора**
2. **Не должно быть кнопки установки PWA**
3. **Не должно быть предложений об установке**

## 🚨 Если что-то не работает:

### **Кассир не показывает предупреждение в Telegram:**
1. Убедитесь, что обновили страницу (Ctrl+F5)
2. Проверьте консоль на ошибки JavaScript
3. Убедитесь, что используете обновленную версию

### **Оператор всё ещё показывает кнопку установки:**
1. Очистите кэш браузера (Ctrl+Shift+Del)
2. Закройте и откройте браузер заново
3. Проверьте, что нет старых service worker'ов

### **PWA не устанавливается в браузере:**
1. Убедитесь, что используете HTTPS
2. Проверьте, что service worker зарегистрирован
3. Попробуйте в режиме инкогнито
