
# 💰 PWA Setup для интерфейса кассира Babay Burger

Интерфейс кассира теперь поддерживает полноценную PWA (Progressive Web App) функциональность, что позволяет кассирам устанавливать приложение на свои устройства и работать с ним как с нативным приложением.

## 🎯 Основные возможности PWA

### ✅ Установка приложения
- **Автоматический prompt**: Браузер предлагает установить приложение через 3 секунды
- **Кастомный prompt**: Красивый интерфейс установки с кнопками "Установить" и "Позже"
- **Умная логика**: Не показывает prompt в течение 24 часов после отклонения
- **Проверка установки**: Автоматически определяет, запущено ли как PWA

### ✅ Офлайн режим
- **Service Worker**: Кэширует статические ресурсы и API данные
- **Стратегии кэширования**:
  - **Cache First**: Для статических ресурсов (CSS, JS, изображения)
  - **Network First**: Для HTML страниц с fallback на кэш
  - **Network Only**: Для API запросов (всегда актуальные данные)
- **Офлайн индикатор**: Показывает статус подключения

### ✅ Push уведомления
- **Автоматический запрос**: Разрешение на уведомления через 5 секунд
- **Уведомления об установке**: Подтверждение успешной установки
- **Кастомные уведомления**: Поддержка действий и иконок
- **Обработка кликов**: Открытие приложения при клике на уведомление

### ✅ Нативный опыт
- **Standalone режим**: Полноэкранное приложение без адресной строки
- **Кастомные стили**: Оптимизированный UI для PWA режима
- **Жесты**: Предотвращение zoom и контекстного меню в PWA
- **Быстрый запуск**: Мгновенная загрузка из кэша

## 📁 Структура файлов PWA

### PWA Манифест
```
public/cashier-manifest.json
```
- Настройки приложения (название, иконки, цвета)
- Ярлыки для быстрого доступа (логин, панель)
- Ориентация экрана и режим отображения
- Категории и связанные приложения

### Service Worker
```
public/cashier-sw.js
```
- Кэширование ресурсов (версия v1.0.0)
- Обработка офлайн режима
- Push уведомления и фоновая синхронизация
- Стратегии кэширования для разных типов запросов

### PWA Иконки
```
public/cashier-icon-*.png (72, 96, 128, 144, 152, 192, 384, 512)
```
- Полный набор иконок для всех устройств
- Поддержка maskable иконок
- Оптимизированы для разных разрешений

## 🧩 React компоненты

### CashierPWAInstallPrompt
```tsx
src/components/cashier/PWAInstallPrompt.tsx
```
- Красивый prompt для установки PWA
- Автоматическое определение возможности установки
- Логика отложенного показа (24 часа)
- Анимированный интерфейс с кнопками действий

### CashierPWAStatus
```tsx
src/components/cashier/PWAStatus.tsx
```
- Индикатор статуса подключения (онлайн/офлайн)
- Показывает режим PWA
- Статус Service Worker
- Компактный дизайн для размещения в header

### useCashierPWA Hook
```tsx
src/hooks/useCashierPWA.ts
```
- Полное управление состоянием PWA
- Регистрация Service Worker
- Обработка установки и событий
- API для проверки обновлений и уведомлений

## 🚀 Использование

### Для кассиров
1. **Откройте** интерфейс кассира в браузере (`/cashier.html`)
2. **Дождитесь** появления prompt установки (через 3-5 секунд)
3. **Нажмите** "Установить" для установки PWA
4. **Наслаждайтесь** нативным опытом работы

### Для разработчиков
1. **Сборка**: `npm run build` включает все PWA файлы
2. **Тестирование**: Используйте Chrome DevTools -> Application -> PWA
3. **Обновление**: Service Worker автоматически обновляется при изменениях

## 🛠️ Технические детали

### Кэширование
- **Статические ресурсы**: Кэшируются навсегда с обновлением при новых версиях
- **API данные**: Network-first стратегия для актуальности
- **HTML страницы**: Network-first с fallback на кэш
- **Шрифты**: Кэшируются с внешних CDN

### Уведомления
- **Push API**: Стандартный API для push уведомлений
- **Service Worker**: Обрабатывает уведомления в фоне
- **Действия**: Поддержка кнопок действий в уведомлениях
- **Иконки**: Кастомные иконки и badges

### Обновления
- **Автоматические**: Проверка обновлений каждые 60 секунд
- **Версионирование**: Кэш обновляется при изменении версии
- **Уведомления**: Пользователь может получать уведомления об обновлениях

## 🔧 Настройка и кастомизация

### Изменение иконок
1. Замените файлы `cashier-icon-*.png` в папке `public/`
2. Обновите манифест `cashier-manifest.json`
3. Пересоберите проект

### Настройка кэширования
1. Отредактируйте `public/cashier-sw.js`
2. Измените `CACHE_URLS` для добавления новых файлов
3. Обновите версию кэша `CACHE_NAME`

### Кастомизация prompt
1. Отредактируйте `CashierPWAInstallPrompt.tsx`
2. Измените стили и тексты
3. Настройте логику показа prompt

## 🚨 Важные замечания

- PWA работает только по HTTPS в продакшене
- Для локального тестирования используйте `localhost` (не `127.0.0.1`)
- Service Worker кэширует файлы агрессивно - для разработки используйте Hard Reload
- Уведомления требуют разрешения пользователя
