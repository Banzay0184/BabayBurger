# 📱 PWA Setup для интерфейса оператора

Интерфейс оператора теперь поддерживает PWA (Progressive Web App) функциональность, что позволяет операторам устанавливать приложение на свои планшеты и работать с ним как с нативным приложением.

## 🎯 Основные возможности PWA

### ✅ Установка приложения
- **Автоматический prompt**: Браузер автоматически предлагает установить приложение
- **Ручная установка**: Кнопка "Установить" в интерфейсе
- **Ярлыки**: Быстрый доступ к новым заказам и всем заказам

### ✅ Офлайн режим
- **Кэширование**: Статические ресурсы и API данные кэшируются
- **Стратегии кэширования**:
  - **Cache First**: Для статических ресурсов (CSS, JS, изображения)
  - **Network First**: Для API запросов с fallback на кэш
- **Индикатор офлайн**: Показывает статус подключения

### ✅ Push уведомления
- **Новые заказы**: Уведомления о новых заказах
- **Действия**: Возможность открыть заказ или закрыть уведомление
- **Вибросигнал**: Тактильная обратная связь

### ✅ Нативный опыт
- **Standalone режим**: Полноэкранное приложение без адресной строки
- **Адаптивный дизайн**: Оптимизирован для планшетов
- **Быстрый запуск**: Мгновенная загрузка из кэша

## 📁 Структура файлов

### PWA Манифест
```
public/operator-manifest.json
```
- Настройки приложения
- Иконки и темы
- Ярлыки для быстрого доступа
- Ориентация экрана (landscape для планшетов)

### Service Worker
```
public/operator-sw.js
```
- Кэширование ресурсов
- Обработка офлайн режима
- Push уведомления
- Фоновая синхронизация

### HTML точка входа
```
operator.html
```
- Отдельная HTML страница для оператора
- PWA мета-теги
- Регистрация Service Worker

## 🔧 Компоненты

### PWAInstallPrompt
```tsx
src/components/operator/PWAInstallPrompt.tsx
```
- Показывает prompt установки
- Обрабатывает выбор пользователя
- Скрывается после установки

### PWAStatus
```tsx
src/components/operator/PWAStatus.tsx
```
- Показывает статус подключения
- Индикатор PWA установки
- Статус Service Worker

### usePWA Hook
```tsx
src/hooks/usePWA.ts
```
- Управление состоянием PWA
- Регистрация Service Worker
- Обработка событий установки

## 🚀 Использование

### Для операторов
1. **Откройте** интерфейс оператора в браузере
2. **Дождитесь** появления prompt установки
3. **Нажмите** "Установить" или используйте кнопку в интерфейсе
4. **Наслаждайтесь** нативным опытом работы

### Для разработчиков
1. **Сборка**: `npm run build` создает отдельные файлы для оператора
2. **Тестирование**: Используйте Chrome DevTools для тестирования PWA
3. **Обновление**: Service Worker автоматически обновляется при изменениях

## 📊 Преимущества

### Для операторов
- ⚡ **Быстрый доступ**: Приложение всегда под рукой
- 📱 **Нативный опыт**: Работает как обычное приложение
- 🔄 **Офлайн режим**: Работает без интернета
- 🔔 **Уведомления**: Не пропустите новые заказы

### Для бизнеса
- 📈 **Увеличение эффективности**: Операторы работают быстрее
- 💰 **Экономия**: Не нужно разрабатывать отдельные приложения
- 🔧 **Простота обновлений**: Обновления через веб-интерфейс
- 📊 **Аналитика**: Полная аналитика использования

## 🛠️ Технические детали

### Кэширование
- **Статические ресурсы**: CSS, JS, изображения кэшируются навсегда
- **API данные**: Кэшируются с TTL для актуальности
- **HTML страницы**: Кэшируются с fallback стратегией

### Уведомления
- **Push API**: Использует стандартный Push API
- **Service Worker**: Обрабатывает уведомления в фоне
- **Действия**: Поддержка действий в уведомлениях

### Совместимость
- **Chrome/Edge**: Полная поддержка
- **Firefox**: Базовая поддержка
- **Safari**: Ограниченная поддержка (iOS 11.3+)

## 📝 Примечания

- PWA работает только по HTTPS в продакшене
- Для тестирования на localhost используйте `localhost` (не `127.0.0.1`)
- Service Worker обновляется автоматически при изменении версии
- Кэш очищается при обновлении версии приложения
