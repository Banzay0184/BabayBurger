# Интерфейс кассира Babay Burger

## Описание
Интерфейс для кассиров ресторанов, позволяющий управлять заказами и отслеживать их статусы.

## Функциональность
- 🔐 Аутентификация кассиров
- 📊 Дашборд со статистикой заказов
- 📋 Просмотр заказов ресторана
- ⚡ Управление статусами заказов:
  - Начать приготовление
  - Отметить как готовый
  - Завершить заказ
- 🏪 Привязка к конкретному ресторану

## Запуск в режиме разработки

```bash
# Установка зависимостей (если еще не установлены)
npm install

# Запуск интерфейса кассира
npm run dev:cashier
```

Интерфейс будет доступен по адресу: `http://localhost:5173/cashier.html`

## Сборка для продакшена

```bash
# Сборка интерфейса кассира
npm run build:cashier
```

## API Endpoints

### Аутентификация
- `POST /api/cashier/auth/login/` - Вход кассира

### Заказы
- `GET /api/cashier/orders/` - Получение заказов
- `GET /api/cashier/orders/dashboard/` - Статистика дашборда
- `POST /api/cashier/orders/{id}/start_processing/` - Начать приготовление
- `POST /api/cashier/orders/{id}/mark_ready/` - Отметить готовым
- `POST /api/cashier/orders/{id}/complete/` - Завершить заказ

## Особенности

1. **Безопасность**: Каждый кассир видит только заказы своего ресторана
2. **Real-time**: Автоматическое обновление данных после действий
3. **Responsive**: Адаптивный дизайн для различных устройств
4. **Интуитивность**: Простой и понятный интерфейс

## Интеграция с системой

Интерфейс кассира интегрирован с:
- Системой операторов (получение заказов после обработки)
- Системой курьеров (передача готовых заказов на доставку)
- Telegram ботом (уведомления о статусах)
