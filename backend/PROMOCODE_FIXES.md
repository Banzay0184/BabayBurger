# Исправления промокода

## Проблема
Изначально промокод был реализован как "один промокод на одного пользователя", что неправильно. Промокод должен быть **многоразовым для всех пользователей**, но **каждый пользователь может использовать его только один раз**.

## Решение
Создана новая модель `PromoCodeUsage` для отслеживания использований промокодов пользователями, а модель `PromoCode` упрощена.

### Изменения в моделях

#### PromoCode
- **Убрано поле `used_by`** (ForeignKey к User)
- **Убрано поле `is_used`** (boolean)
- **Убрано поле `used_at`** (DateTimeField)
- **Добавлено поле `max_uses`** (PositiveIntegerField) - максимальное количество использований (0 = безлимит)

#### PromoCodeUsage (новая модель)
- **`promo_code`** - ссылка на промокод
- **`user`** - ссылка на пользователя
- **`used_at`** - дата использования
- **`unique_together`** - один пользователь может использовать промокод только один раз

### Логика работы
1. **Проверка валидности**: 
   - Проверяется активность промокода
   - Проверяется срок действия
   - Проверяется минимальная сумма заказа
   - Проверяется, использовал ли пользователь этот промокод ранее
   - Проверяется лимит использований (если установлен)

2. **После использования**:
   - Создается запись в `PromoCodeUsage`
   - Промокод остается активным для других пользователей
   - Пользователь больше не может использовать этот промокод

### Примеры использования
- **Промокод "SAVE20"** с `max_uses=100` может использовать 100 разных пользователей
- **Каждый пользователь** может использовать его только 1 раз
- **После 100 использований** промокод автоматически блокируется

## Дополнительные улучшения

### Тип заказа в истории
Добавлено отображение типа заказа (доставка/самовывоз) в истории заказов:
- **Иконка и текст** типа заказа в заголовке заказа
- **Отдельный блок** с типом заказа в деталях
- **Условное отображение** стоимости доставки только для заказов с доставкой
- **Указание типа заказа** для самовывоза

### Админка
- **PromoCodeAdmin**: показывает количество использований, убраны ссылки на `used_by`
- **PromoCodeUsageAdmin**: новая админка для просмотра использований промокодов

## Миграции
- Создана миграция `0014_remove_promocode_is_used_remove_promocode_used_at_and_more`
- Убраны старые поля из `PromoCode`
- Создана новая таблица `PromoCodeUsage`

## Тестирование
Создан и успешно выполнен тест, подтверждающий:
- Множественные использования промокода разными пользователями
- Блокировка повторного использования одним пользователем
- Блокировка после достижения лимита использований
- Корректное отслеживание использований
