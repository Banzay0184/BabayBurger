## 🚀 Шаги для полного тестирования

### 1. Остановите текущий Django сервер
```bash
# Нажмите Ctrl+C в терминале где запущен сервер
```

### 2. Установите uvicorn (если не установлен)
```bash
cd backend
pip install uvicorn
```

### 3. Запустите сервер с ASGI поддержкой
```bash
cd backend
python run_asgi.py
```

**Или альтернативно:**
```bash
cd backend
uvicorn config.asgi:application --host 0.0.0.0 --port 8000 --reload
```

### 4. Проверьте WebSocket соединение
```bash
cd backend
python test_websocket_live.py
```

### 5. Откройте операторский интерфейс
```bash
cd frontend
npm run dev:operator
```

Затем откройте: `http://localhost:5174`

## 🚨 Troubleshooting

### HTTP 500 при WebSocket соединении
**Причина:** Django запущен без ASGI поддержки
**Решение:** Перезапустите с `python run_asgi.py`

### WebSocket не подключается
**Проверьте:**
1. Redis запущен: `redis-server`
2. Сервер запущен с ASGI: `python run_asgi.py`
3. Нет ошибок в логах сервера

### Сообщения не приходят
**Проверьте:**
1. Channel Layer работает (тест прошел ✅)
2. Signals зарегистрированы (тест прошел ✅)
3. Операторы созданы в базе данных
