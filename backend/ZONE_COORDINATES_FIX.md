# Исправление координат зон доставки

## Проблема
Оператор из Бухары не видел заказы из города Бухара, хотя был назначен на зону "Центр Бухары".

## Диагностика
При запуске `debug_operator_zones.py` было обнаружено:

```
🛒 Заказ #62
   Город: Бухара
   Координаты: 39.7687530, 64.4139670
   Подходящих операторов: 0
     ❌ Нет подходящих операторов!
```

**Причина**: Координаты зоны Бухары были перепутаны местами:
- **Было**: 64.455600, 39.768100 (широта, долгота)
- **Должно быть**: 39.768100, 64.455600 (широта, долгота)

## Решение
Создан скрипт `fix_zone_coordinates.py` для автоматического исправления координат:

```python
# Для Узбекистана: широта ~39-41, долгота ~60-67
if lat > 50:  # Если "широта" больше 50, то это долгота
    # Меняем местами
    zone.center_latitude = lng
    zone.center_longitude = lat
```

## Результат
После исправления:

```
🛒 Заказ #62
   Город: Бухара
   Координаты: 39.7687530, 64.4139670
   Подходящих операторов: 1
     ✅ admin2: Заказ доставки в зоне 'Центр Бухары'
```

## Проверка других зон
- **Зона Каган**: координаты корректны (39.722200, 64.551700)
- **Зона Бухары**: исправлена (39.768100, 64.455600)

## Тестирование
1. Запустить `python debug_operator_zones.py` для проверки
2. Создать заказ из Бухары
3. Убедиться, что оператор admin2 видит заказ

## Примечание
При создании новых зон доставки важно правильно указывать координаты:
- **Широта (latitude)**: 39-41 для Узбекистана
- **Долгота (longitude)**: 60-67 для Узбекистана
